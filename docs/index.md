# Welcome to PAAF

**PAAF (Personalized Agentic Assistant Framework)** is a local-first, privacy-preserving framework where **the user owns the mind**.

## Core Philosophy

1. **User Owns the Mind:** System prompts, model profiles, and peer routing rules are defined transparently in `paaf.yaml`.
2. **Nothing Hidden:** Every system prompt and handoff instruction can be byte-exact inspected via `paaf prompt`.
3. **In-Process & Modular Skills:** Extend assistant capabilities cleanly via versioned skills and MCP server integrations.
