# Scope Boundaries & Roadmap

PAAF maintains strict transparency regarding feature availability.

## Current Delivered Scope (Phases 1 - 6)

- Monolithic Python package (`paaf`)
- Multi-model profiles, fallback chains, and reload tiers
- LLM-driven handoff agent mesh with observer guardrails
- Unified Tool Registry (built-in, MCP, skills) with permission tiers
- Skill packaging, autodiscovery loader, and staging installation

## Explicit Non-Existent Scope (Phase 13 Roadmap)

The following components **do NOT exist yet** and are scheduled for future development in Phase 13:

- **Voice & Audio Graph Subsystem:** Real-time STT/TTS audio streaming does not exist yet.
- **Session Barge-in & Interruption:** Asynchronous session interruption does not exist yet.
- **Appliance Background Service:** Daemon mode / systemd service wrapper does not exist yet.
- **Desktop UI Application:** Graphical desktop app wrapper does not exist yet.
