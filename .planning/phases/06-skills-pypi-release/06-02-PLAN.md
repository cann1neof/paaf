<objective>
Implement dynamic skill enable/disable toggles via `paaf skill enable <name>` and `paaf skill disable <name>` updating `paaf.yaml`, with instant hot-reloading in the unified tool registry and prompt composer, persona fragment appending (`--- Skill: <name> ---`), and mandatory in-process no-sandbox security disclosure (SKILL-05).
</objective>

<threat_model>
- **Threat T-06-05 (Hidden Prompt Injection & Unseen Instructions):** Skill persona fragments added to prompt hiddenly or modifying base system instructions unpredictably.
  - *Mitigation:* Skill persona fragments are appended verbatim to base prompt with clear section headers (`--- Skill: <name> ---`), strictly obeying the `join == compose` invariant (PERS-04/05). Prompt inspector (`paaf prompt`) shows full verbatim composed prompt.
- **Threat T-06-06 (Stale Tool Execution):** Disabling a skill leaves registered skill tools active in memory or available to models.
  - *Mitigation:* `SkillManager.disable_skill` updates `paaf.yaml` and hot-reloads `ToolRegistry`, unregistering all tools sourced from `skill:<skill_name>` immediately.
</threat_model>

<requirements_addressed>
- SKILL-04: Skill enable/disable toggle updating `paaf.yaml` and hot-reloading tool registry & prompt composer
- SKILL-05: Mandatory security disclosure in prompt/docs regarding in-process skill execution
</requirements_addressed>

    Create `packages/paaf-llm/src/paaf_llm/skills/manager.py`:
    - Implement `SkillManager`:
      - `enable_skill(skill_name: str, config_store: ConfigStore) -> None`:
        Updates `paaf.yaml` setting `skills[skill_name].enabled = True`, triggers registry reload (registers skill tools) and prompt composer update.
      - `disable_skill(skill_name: str, config_store: ConfigStore) -> None`:
        Updates `paaf.yaml` setting `skills[skill_name].enabled = False`, unregisters skill tools from `ToolRegistry` (`registry.unregister_source(f"skill:{skill_name}")`), and clears skill persona fragment from `PromptComposer`.
      - `get_active_persona_fragments(config: AppConfig) -> list[str]`:
        Reads all enabled skills from `AppConfig`, loads their declared `persona_fragment` file (`prompt.md` or `persona.md`), and returns formatted string fragments prefixed with `--- Skill: <name> ---`.
  </action>

  </verify>
