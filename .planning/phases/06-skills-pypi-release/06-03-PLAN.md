<objective>
Package the framework into a single monolithic `paaf` PyPI package bundling `paaf_core`, `paaf_trace`, and `paaf_llm` (OSS-01), build a clean-venv release verification script (`scripts/check_release_venv.sh`), and publish a comprehensive MkDocs Material documentation site (OSS-02) covering install, config, agent mesh, skills, API, and explicit roadmap scope boundaries (disclosing voice & appliance components do not exist yet).
</objective>

<threat_model>
- **Threat T-06-07 (Release Rot & Workspace Dependency Leak):** The published PyPI wheel fails in clean environments because it secretly depends on local repo files or uncommitted packages.
  - *Mitigation:* `scripts/check_release_venv.sh` builds the monolithic `paaf` wheel, creates a clean temporary virtual environment outside the workspace, installs the wheel with no repo access, and executes end-to-end smoke tests (`paaf chat`, agent mesh handoffs, `paaf prompt`, skill loading).
- **Threat T-06-08 (Misleading Documentation & False Claims):** Public documentation implies voice or desktop appliance features are already functional.
  - *Mitigation:* Include explicit "Roadmap & What Exists" page (`docs/roadmap/scope.md`) stating plainly that voice, appliance, and desktop features do NOT exist yet and land in Phase 13.
</threat_model>

<requirements_addressed>
- OSS-01: Single monolithic `paaf` PyPI package bundling `paaf_core`, `paaf_trace`, `paaf_llm`
- OSS-02: MkDocs Material documentation site covering install, config, agent mesh, skills, API, and explicit scope boundaries
</requirements_addressed>
