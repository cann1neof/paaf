# Executive Summary & Intent

Plan 03 delivers the core text processing engines of `paaf-voice`: `TTSSanitizer` and `SentenceAggregator`.
`TTSSanitizer` cleans LLM streaming text by stripping markdown syntax, code blocks, raw URLs, and emojis (`So` category) while converting markdown links `[text](url)` to anchor text (D-13, D-14), preventing speech engines from attempting to synthesize formatting or code symbols out loud.

`SentenceAggregator` accumulates LLM token streams into natural speakable sentences across Latin, Cyrillic, Hebrew (Sof Pasuq `׃`), and CJK scripts without per-language settings or external NLTK dependencies (D-05, VOICE-06). It implements early-emission dual character thresholds (20 chars for chunk 1 vs 60 chars for subsequent chunks) (D-09, D-10), token count safety fallbacks (D-12), abbreviation/decimal regex protection (D-08), script transition preservation (D-06), and stream flushing (D-07). `TTSSanitizer` is integrated directly into sentence chunk emission (D-16).

## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Regular Expression Denial of Service (ReDoS) & Input Injection
- **Threat**: Maliciously crafted LLM output token streams containing deeply nested or repeated markdown formatting, URLs, or punctuation causing catastrophic backtracking in regular expressions during text sanitization or sentence boundary detection.
- **Impact**: CPU exhaustion and thread blocking during streaming voice response synthesis.
- **Mitigation Strategy**:
  1. All regular expressions in `TTSSanitizer` and `SentenceAggregator` use non-nested, non-backtracking patterns with explicit character classes.
  2. Compiled static `re.Pattern` objects instantiated at module load time.
  3. Emoji removal relies on linear single-pass lookup via Python stdlib `unicodedata.category(char) == 'So'` rather than complex multi-byte regex matching.
</threat_model>

- `packages/paaf-voice/tests/test_sanitizer.py`

**Implementation Details:**
1. Create `src/paaf_voice/sanitizer.py`:
   - `TTSSanitizer` class with static `sanitize(text: str) -> str` method.
   - Transformation pipeline:
     1. Strip fenced code blocks (```...```) -> `""`.
     2. Convert markdown links `[text](url)` -> `text`.
     3. Strip raw URLs (`http://...`, `https://...`) -> `""`.
     4. Remove markdown headings (`#`, `##`, `###`).
     5. Remove inline backticks (keeping code text) -> `` `foo` `` -> `foo`.
     6. Remove bold/italic markers (`**`, `*`, `__`, `_`, `~`).
     7. Strip Emojis (`unicodedata.category(char) == "So"`).
     8. Normalize multi-space whitespace to single space.
2. Create `tests/test_sanitizer.py`:
   - Test fenced code block removal (`"Here is code ```python print('hi')``` end"` -> `"Here is code end"`).
   - Test markdown link conversion (`"Click [here](https://paaf.ai) now"` -> `"Click here now"`).
   - Test raw URL stripping (`"Visit https://paaf.ai today"` -> `"Visit today"`).
   - Test emoji stripping (`"Hello world 👋! 😊"` -> `"Hello world !"`).
   - Test header and formatting stripping (`"# Header\n**bold** and *italic*"` -> `"Header bold and italic"`).

### Task 2: Implement `SentenceAggregator` & Multilingual Test Suite

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/aggregator.py`
- `packages/paaf-voice/src/paaf_voice/__init__.py`
- `packages/paaf-voice/tests/test_aggregator.py`

**Implementation Details:**
1. Create `src/paaf_voice/aggregator.py`:
   - `@dataclass(frozen=True, slots=True)` `AggregatorConfig`:
     - `first_chunk_min_chars: int = 20`
     - `subsequent_min_chars: int = 60`
     - `max_first_chunk_tokens: int = 15`
   - `SentenceAggregator`:
     - `SENTENCE_TERMINATORS = {".", "!", "?", "׃", "。", "！", "？"}` (Latin, Cyrillic, Hebrew Sof Pasuq `U+05C3`, CJK).
     - `CLAUSE_PUNCTUATION = {",", ";", ":"}`.
     - `ABBREVIATION_PATTERN = re.compile(r"\b(Dr|Mr|Mrs|Ms|Prof|Sr|Jr|e\.g|i\.e|vs|etc|St|approx)\.$", re.IGNORECASE)`.
     - `DECIMAL_PATTERN = re.compile(r"\d+\.\d+$")`.
     - Method `add_token(token: str) -> list[str]`: Appends token to internal buffer, increments token count, evaluates boundary rules.
     - Method `flush() -> list[str]`: Cleans remaining buffer via `TTSSanitizer.sanitize()` and yields it if non-empty. Reset state.
     - Method `aggregate_stream(token_stream: AsyncIterable[str]) -> AsyncIterator[str]`: Consumes stream, yields chunks.
     - Internal evaluation logic:
       - Protect decimals (`3.14`) and abbreviations (`Dr.`) from splitting.
       - Chunk 1 (before any chunk emitted): If buffer length >= 20 chars AND encountering clause punctuation or sentence terminator -> emit chunk cleaned via `TTSSanitizer`.
       - Chunk 1 Safety Fallback: If token count >= 15 OR sentence terminator reached, emit chunk even if chars < 20.
       - Subsequent Chunks (after chunk 1 emitted): Ignore clause punctuation. Emit ONLY when encountering sentence terminator AND buffer length >= 60 chars (or on sentence boundary).
2. Update `src/paaf_voice/__init__.py`:
   - Re-export `SentenceAggregator`, `AggregatorConfig`, `TTSSanitizer`.
3. Create `tests/test_aggregator.py`:
   - Test Latin sentence boundary (`"Hello world. How are you?"`).
   - Test Cyrillic sentence boundary (`"Привет мир. Как дела?"`).
   - Test Hebrew Sof Pasuq boundary (`"שלום עולם׃ מה שלומך?"`).
   - Test CJK sentence boundary (`"こんにちは。元気ですか？"`).
   - Test decimal protection (`"The value is 3.14. Next sentence."` -> splits after `3.14.`, not `3.`).
   - Test abbreviation protection (`"Dr. Smith is here. Welcome."` -> splits after `here.`, not `Dr.`).
   - Test mid-sentence script transition (`"Я запускаю Python script. Все отлично."` -> no split on `Python script`).
   - Test dual threshold early emission (Chunk 1 emits at clause `,` when >= 20 chars; Chunk 2 ignores clause `,` and waits for sentence terminator `.`).
   - Test safety fallback (emits chunk 1 after 15 tokens even without punctuation).
   - Test `flush()` on stream completion.

**Verification Command:**
```bash
uv run pytest packages/paaf-voice/tests/test_aggregator.py
```
