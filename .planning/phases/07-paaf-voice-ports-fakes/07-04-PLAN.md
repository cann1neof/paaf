# Executive Summary & Intent

Plan 04 completes Phase 07 by establishing hardware-free audio fixture testing and empirical TTFA performance verification (VOICE-11, D-11, D-15).
It implements pure Python stdlib audio generators (`generate_pcm_sine_bytes`, `create_wav_bytes`) in `paaf_voice.testing.generators`, provisions standard PCM WAV test fixture files in `tests/fixtures/wav/`, and verifies end-to-end reading and playback streaming through `FakeAudioSource` and `FakeAudioSink` (~80% test coverage without micro-phones or speakers).

Finally, it implements `test_ttfa_benchmark.py`, empirically demonstrating in CI that PAAF's short first-chunk strategy (`first_chunk_min_chars=20` + clause punctuation) achieves significantly lower Time-To-First-Audio (TTFA) token latency compared to a single long-chunk baseline (`first_chunk_min_chars=60`).

## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Resource Exhaustion & Data Validation in Audio Fixtures
- **Threat**: Corrupted WAV file fixtures or unbounded programmatic audio byte generation causing high memory allocation or CPU infinite loops during CI test suite execution.
- **Impact**: Runner crash, memory exhaustion, or CI timeout.
- **Mitigation Strategy**:
  1. Programmatic generators restrict sample rates and frame sizes to validated parameters (e.g. 16kHz 16-bit mono PCM).
  2. Stdlib `wave` module strict header validation when parsing WAV fixture files.
  3. Deterministic benchmark iterations with static token lists and zero network/time sleep dependencies.
</threat_model>

- `packages/paaf-voice/tests/fixtures/wav/tone_440hz_16k_1s.wav`
- `packages/paaf-voice/tests/test_wav_fixtures.py`

**Implementation Details:**
1. Create `src/paaf_voice/testing/generators.py`:
   - `generate_pcm_sine_bytes(duration_s: float, frequency: float = 440.0, sample_rate: int = 16000) -> bytes`: Uses `math.sin` and `struct.pack('<h', ...)` to generate raw 16-bit signed mono PCM sine wave bytes.
   - `create_wav_bytes(pcm_data: bytes, sample_rate: int = 16000, channels: int = 1, sample_width: int = 2) -> bytes`: Wraps raw PCM bytes in a valid RIFF WAV buffer using stdlib `wave` module and `io.BytesIO`.
2. Update `src/paaf_voice/testing/__init__.py`:
   - Re-export `generate_pcm_sine_bytes`, `create_wav_bytes`.
3. Create static binary WAV files in `tests/fixtures/wav/`:
   - `silence_16k_1s.wav`: 1 second of silent 16kHz 16-bit PCM mono (32,000 bytes raw PCM + 44 bytes header = 32,044 bytes).
   - `tone_440hz_16k_1s.wav`: 1 second of 440Hz sine wave 16kHz 16-bit PCM mono.
4. Create `tests/test_wav_fixtures.py`:
   - Test reading static WAV fixtures using stdlib `wave.open()`. Assert sample rate == 16000, channels == 1, sample width == 2.
   - Test loading WAV PCM bytes into `FakeAudioSource`, running `read_frames()`, writing to `FakeAudioSink`, and asserting `get_playhead_position() == 1.0` seconds.
   - Test `generate_pcm_sine_bytes` and `create_wav_bytes` producing valid, parseable WAV header structures.

**Verification Command:**
```bash
uv run pytest packages/paaf-voice/tests/test_wav_fixtures.py
```

### Task 2: Implement Empirical TTFA Benchmark Test Suite

**Files Modified:**
- `packages/paaf-voice/tests/test_ttfa_benchmark.py`

**Implementation Details:**
1. Create `tests/test_ttfa_benchmark.py`:
   - Define tokenized LLM stream containing an early clause: `tokens = ["Hello ", "there, ", "I ", "am ", "ready ", "to ", "assist ", "you. ", "How ", "can ", "I ", "help?"]`.
   - Test short dual threshold strategy (`first_chunk_min_chars=20`, clause punctuation enabled):
     - Feed tokens one by one into `SentenceAggregator`. Record token index `i` when first chunk is emitted.
   - Test baseline single long threshold strategy (`first_chunk_min_chars=60`):
     - Feed identical tokens into separate `SentenceAggregator`. Record token index `j` when first chunk is emitted.
   - Assert `first_chunk_token_index_short < first_chunk_token_index_long`.
   - Assert `chunks_short[0] == "Hello there,"` (first clause emitted early).
   - Assert total aggregated text output of both strategies match after stream completion (`flush()`).

**Verification Command:**
```bash
uv run pytest packages/paaf-voice/tests/test_ttfa_benchmark.py
```
