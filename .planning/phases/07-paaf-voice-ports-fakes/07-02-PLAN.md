# Executive Summary & Intent

Plan 02 completes the public `paaf_voice.testing` suite by implementing test double implementations for all four voice processing engines: `FakeSTT`, `FakeTTS`, `FakeWakeWord`, and `FakeVAD` (D-02, VOICE-02).
These test doubles allow downstream framework components (`paaf-session`, CLI applications, and unit test suites) to run full voice turn state machines without initializing external ML models, local GPU runtimes, or hardware drivers.

Each fake engine conforms strictly to the `@runtime_checkable` `Protocol` boundaries established in Plan 01, supports explicit `warmup()` lifecycle pre-initialization (VOICE-10), and records execution history for deterministic assertion in CI.

---

<threat_model>
## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: State Manipulation & Unhandled Exceptions in Async Streams
- **Threat**: Unbounded loop execution or silent state corruption in fake stream generators during test suite execution, leading to deadlocks or leaked state across test cases.
- **Impact**: Test suite instability, false positives in CI, or hanging async generators.
- **Mitigation Strategy**:
  1. Stream iterators in `FakeSTT` and `FakeTTS` operate on explicit bounded input streams or pre-configured string outputs.
  2. Recorded execution state (`synthesized_texts`, `transcribed_streams`) stored in instance-local lists, preventing inter-test state leakages.
  3. Non-blocking async generator methods yielding control gracefully via stdlib `asyncio`.
</threat_model>

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/testing/fakes.py`
- `packages/paaf-voice/src/paaf_voice/testing/__init__.py`

**Implementation Details:**
1. In `src/paaf_voice/testing/fakes.py`, implement:
   - `FakeSTT`:
     - Constructor parameters: `canned_transcriptions: list[STTResult] | list[str] | None = None`, `default_text: str = "Fake transcription"`.
     - Method `transcribe_stream(audio_stream: AsyncIterable[AudioFrame]) -> AsyncIterator[STTResult]`: Consumes frames from stream, yields partial and final `STTResult` objects based on canned list or default text. Tracks `transcribed_stream_count: int`.
     - Method `warmup() -> None`: Sets `is_warmed_up = True`.
   - `FakeTTS`:
     - Constructor parameters: `frame_duration_ms: int = 20`, `sample_rate: int = 16000`.
     - Method `synthesize(text: str, voice_id: str | None = None) -> AsyncIterator[AudioFrame]`: Records `text` into `synthesized_texts: list[str]`. Calculates number of 20ms frames proportional to character count (`max(1, len(text) // 5)`). Yields standard PCM audio frames.
     - Method `warmup() -> None`: Sets `is_warmed_up = True`.
   - `FakeWakeWord`:
     - Constructor parameters: `target_keyword: str = "hey_paaf"`, `always_detect: bool = False`.
     - Method `detect(frame: AudioFrame) -> WakeWordResult`: Returns `WakeWordResult(detected=True, keyword=...)` if manual `trigger()` was called or `always_detect` is True.
     - Helper method `trigger(keyword: str | None = None) -> None`: Sets manual trigger state.
     - Method `warmup() -> None`: Sets `is_warmed_up = True`.
   - `FakeVAD`:
     - Constructor parameters: `speech_timeline: list[bool] | None = None`, `default_speech: bool = True`.
     - Method `process_frame(frame: AudioFrame) -> VADResult`: Pops next state from `speech_timeline` or returns `default_speech`.
     - Helper method `set_timeline(timeline: list[bool]) -> None`.
     - Method `warmup() -> None`: Sets `is_warmed_up = True`.
2. In `src/paaf_voice/testing/__init__.py`:
   - Re-export `FakeSTT`, `FakeTTS`, `FakeWakeWord`, `FakeVAD`.

**Implementation Details:**
1. In `tests/test_fakes.py`, write tests for all 4 fake engines:
