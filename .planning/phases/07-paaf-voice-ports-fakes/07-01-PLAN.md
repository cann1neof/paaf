# Executive Summary & Intent

Plan 01 establishes the foundational domain contracts and audio stream test doubles for `paaf-voice`.
Following PAAF's **fake-adapter-first architecture**, all core voice port protocols (`AudioSource`, `AudioSink`, `STT`, `TTS`, `WakeWord`, `VAD`) are defined using pure Python `typing.Protocol` with `@runtime_checkable` (D-01) alongside immutable PAAF audio value objects (`AudioFrame`, `STTResult`, `WakeWordResult`, `VADResult`).

In addition, Plan 01 implements the audio hardware test doubles in the public package `paaf_voice.testing` (D-02): `FakeAudioSink` with virtual playhead tracking across `instant`, `1x`, and `stepped` modes and acoustic echo cancellation (AEC) reference tap extraction (D-03, VOICE-09), and `FakeAudioSource` for fixed 20ms PCM frame streaming (D-04).

Everything is implemented with zero external audio or ML dependencies (Python 3.12 Standard Library only).

<threat_model>
## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Audio Buffer Bounds & Memory Safety / Input Validation
- **Threat**: Malformed frame parameters (e.g. zero/negative sample rate, channels, or sample width) causing division-by-zero, buffer overruns, or unbounded memory growth in `FakeAudioSink` during continuous audio streaming or reference tap extraction.
- **Impact**: Denial of Service (DoS) or process crash during audio pipeline execution.
- **Mitigation Strategy**:
  1. Immutable value object design using `@dataclass(frozen=True, slots=True)` for `AudioFrame` and result objects.
  2. Guard properties on `AudioFrame` ensuring `duration_ms` returns 0.0 for invalid sample rate / channel values instead of throwing `ZeroDivisionError`.
  3. Strict byte slicing in `FakeAudioSink.get_reference_tap()` based on exact sample calculations, capping memory accumulation at target byte boundaries.
</threat_model>

## Tasks

### Task 1: Define Core Port Interfaces & Immutable Data Models

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/ports.py`
- `packages/paaf-voice/tests/test_ports.py`

**Implementation Details:**
1. Create `src/paaf_voice/ports.py`:
   - `@dataclass(frozen=True, slots=True)` value objects:
     - `AudioFrame`: `data: bytes`, `sample_rate: int = 16000`, `channels: int = 1`, `sample_width: int = 2`, `timestamp_ms: float = 0.0`. Property `duration_ms` calculating `(len(data) / bytes_per_ms)`.
     - `STTResult`: `text: str`, `is_final: bool = True`, `language: str | None = None`, `confidence: float = 1.0`.
     - `WakeWordResult`: `detected: bool`, `keyword: str | None = None`, `confidence: float = 0.0`.
     - `VADResult`: `is_speech: bool`, `confidence: float = 0.0`.
   - `@runtime_checkable` `Protocol` boundaries:
     - `AudioSource`: `read_frames(frame_duration_ms: int = 20) -> AsyncIterator[AudioFrame]`, `start() -> None`, `stop() -> None`.
     - `AudioSink`: `write_frame(frame: AudioFrame) -> None`, `get_playhead_position() -> float`, `get_reference_tap() -> bytes`.
     - `STT`: `transcribe_stream(audio_stream: AsyncIterable[AudioFrame]) -> AsyncIterator[STTResult]`, `warmup() -> None`.
     - `TTS`: `synthesize(text: str, voice_id: str | None = None) -> AsyncIterator[AudioFrame]`, `warmup() -> None`.
     - `WakeWord`: `detect(frame: AudioFrame) -> WakeWordResult`, `warmup() -> None`.
     - `VAD`: `process_frame(frame: AudioFrame) -> VADResult`, `warmup() -> None`.
2. Create `tests/test_ports.py`:
   - Assert `isinstance` check works for `@runtime_checkable` protocols without requiring inheritance.
   - Assert `AudioFrame` immutability (modifying attributes raises `FrozenInstanceError`).
   - Assert `duration_ms` calculation for standard 20ms frame (320 samples @ 16kHz 16-bit mono = 640 bytes = 20.0ms).
   - Assert no external non-stdlib imports in `paaf_voice.ports`.

**Verification Command:**
```bash
uv run pytest packages/paaf-voice/tests/test_ports.py
```

### Task 2: Implement Audio Sink & Source Test Doubles

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/testing/fakes.py`
- `packages/paaf-voice/src/paaf_voice/testing/__init__.py`
- `packages/paaf-voice/src/paaf_voice/__init__.py`
- `packages/paaf-voice/tests/test_fakes.py`

**Implementation Details:**
1. Create `src/paaf_voice/testing/fakes.py`:
   - `FakeAudioSink`:
     - Constructor: `mode: Literal["instant", "1x", "stepped"] = "instant"`.
     - Attributes: `recorded_frames: list[AudioFrame]`, `_total_samples_written: int`, `_start_wall_time: float | None`, `_stepped_time_s: float`.
     - `write_frame(frame)`: records frame, calculates sample count `len(data) // (channels * sample_width)`, tracks wall time on first frame.
     - `step(duration_ms)`: advances `_stepped_time_s` for `stepped` mode testing.
     - `get_playhead_position()`: returns playback position in seconds based on mode.
     - `get_reference_tap()`: returns played PCM bytes up to current playhead position for AEC.
   - `FakeAudioSource`:
     - Constructor: `pcm_data: bytes`, `sample_rate: int = 16000`, `realtime: bool = False`.
     - `start()`, `stop()` state control.
     - `read_frames(frame_duration_ms=20)`: yields fixed 20ms `AudioFrame` chunks from `pcm_data`. Zero-pads trailing incomplete frame.
2. Create `src/paaf_voice/testing/__init__.py`:
   - Re-export `FakeAudioSink`, `FakeAudioSource`.
3. Update `src/paaf_voice/__init__.py`:
   - Re-export core ports (`AudioFrame`, `STTResult`, `WakeWordResult`, `VADResult`, `AudioSource`, `AudioSink`, `STT`, `TTS`, `WakeWord`, `VAD`).
4. Create `tests/test_fakes.py`:
   - Test `FakeAudioSink` in `instant` mode (playhead equals total sample duration).
   - Test `FakeAudioSink` in `stepped` mode (`step(100)` advances position by 0.1s up to total written).
   - Test `FakeAudioSink.get_reference_tap()` returning exact sub-byte slices matching playhead position.
   - Test `FakeAudioSource` yielding frames of exact expected byte size (640 bytes for 20ms @ 16kHz).

**Verification Command:**
```bash
uv run pytest packages/paaf-voice/tests/test_fakes.py
```
