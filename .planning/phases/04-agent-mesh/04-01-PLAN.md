## Phase Goal

**As a** self-hoster who declared a peer graph in YAML, **I want to** have the model that is currently awake choose, itself, to hand the conversation to one of its declared peers — and have that peer see everything said so far — **so that** the right model answers without me writing a single routing rule, and a model that names a peer it was never given is stopped rather than obeyed.

<objective>
Make the Phase-3 mesh seam live end to end for the first time: the port grows a *second*, optional tool-calling protocol (leaving `ChatAdapter` untouched, D-02); `mesh.py` builds one `transfer_to_<peer>` tool per declared peer and deterministically validates whatever the model calls; `Agent.turn` becomes a handoff loop around the existing `_run_chain`; and `FakeAdapter` can script a handoff so all of it is provable with the agent framework uninstalled.

Purpose: MESH-01 (the model decides, per D-01's tool-call signal), MESH-02 (belt-and-braces peer enforcement — capability removal AND a runtime guard), MESH-03 (the receiving agent gets the full conversation, and the handoff call never poisons history).
Output: `mesh.py` (new), amended `ports.py` / `agent.py` / `fake/__init__.py` / `__init__.py`, `tests/test_mesh.py` (new, force-included), `make_mesh_config` fixture.
</objective>
