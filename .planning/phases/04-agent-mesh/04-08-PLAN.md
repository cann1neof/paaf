## Phase Goal

**As a** user who was told the assistant supervises its own handoffs, **I want to** be told plainly when it is not doing that — because I never declared a supervisor, or because the one I declared is unreachable — and to be able to hook the moment a supervisor corrects a route, **so that** "the system enforces your constraints" is a claim I can check rather than one I have to take on faith.

<objective>
Finish the observer by making its absence and its failure as visible as its presence. Three honesty properties, each one a place where a plausible implementation would go quiet.

**D-07: unobserved is a state, not a silence.** No `observer` profile means the mesh runs unobserved and says so — a startup line and a mark on every handoff record. This is also the honest caveat that D-13's ruling rests on: the observer counts as "the system" for MESH-06 *because* it is on by default, and the one guarantee that holds in every configuration, observed or not, is the deterministic peer guard.

**OQ-4: fail open, loudly.** The observer inherits `ModelProfile.fallback_chain` like any other profile. If that whole chain degrades, the handoff is approved rather than blocked — an unreachable supervisor must not break all routing — but the same running-unobserved notice fires and a trace row records it. Silent fail-open is forbidden; a supervisor that quietly stopped supervising is worse than one that was never configured.

**D-05: the correction is hookable.** The founder's words were "emitting some signal and letting everyone know that it happened (so we can use it as endpoint and light a flashlight or something)". That means a real observable surface in the headless library, not a trace row someone might read later. The `MeshSignalSink` Protocol from plan 04-01 is that surface, and this plan proves every signal kind actually fires.

Purpose: MESH-06 (D-07, OQ-4, D-05), MESH-04/PERS-05 (the veto refusal text is inspectable too).
Output: the unobserved notice, the fail-open path, the correction signal end-to-end, and the exhaustiveness meta-test that keeps the channel honest.
</objective>
