# Executive Summary & Intent

Plan 05 completes Phase 8 by delivering the real multilingual TTS engine adapter (`ChatterboxTTS`), validating the startup `warmup()` readiness gate across all voice engines (VOICE-10, D-11), and documenting Chatterbox PerTh synthetic audio watermarking characteristics explicitly (VOICE-12).

`ChatterboxTTS` wraps Chatterbox / Dicta-ONNX models to synthesize mixed-language replies (EN, RU, HE, ES) in a single target voice identity without per-language voice switching (VOICE-04). In addition, every engine implementation verified across Phase 8 (`FasterWhisperSTT`, `WhisperCppSTT`, `ChatterboxTTS`, `OpenWakeWordEngine`, `SileroVADEngine`) implements `warmup()`, loading weight tensors and executing a 20ms silence dummy inference pass prior to system readiness.

<threat_model>
## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Startup Race Conditions & Uninitialized Memory Access
- **Threat**: Voice assistant advertising system readiness over mDNS or REST before ML weights are fully loaded into memory, causing first-turn inference crashes or severe latency spikes.
- **Impact**: System unresponsiveness, 5-second initial turn delays, high error rate on boot.
- **Mitigation Strategy**:
  1. `warmup()` method MUST execute synchronously or await completion before voice stack readiness state becomes `True`.
  2. Exception during `warmup()` immediately marks engine `ready: False` and prevents system readiness advertisement.
</threat_model>
