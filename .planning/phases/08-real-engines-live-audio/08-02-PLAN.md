# Executive Summary & Intent

Plan 02 implements the explicit model management CLI and weight presence consent gate in compliance with requirement PRIV-06 and decisions D-04 and D-05. PAAF guarantees zero background model downloads — any model download requires explicit user invocation of the CLI command `paaf voice download-models`.

If an engine is instantiated without model weights present in `~/.cache/paaf/models/`, it raises `ModelMissingError` containing the exact CLI command to run rather than silently downloading multi-hundred-megabyte model files over the network.

---

<threat_model>
## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Privacy / Consent & Network Egress Boundary
- **Threat**: Engines downloading model binaries automatically from Hugging Face or external URLs without explicit user consent, violating PAAF's privacy posture and local offline boundary.
- **Impact**: Unwanted network traffic, tracking via Hugging Face model requests, user bandwidth consumption, silent network leakage.
- **Mitigation Strategy**:
  1. `ModelMissingError` gate raised immediately at engine boot if local model path/file is missing.
  2. Automatic downloads disabled by default in underlying library calls (`download_root` explicit check; no automatic `fetch` calls during initialization).
  3. CLI progress bar rendering during explicit `paaf voice download-models` execution showing destination directory and weight size.
</threat_model>

### Task 1: Define Model Missing Exception & Weight Verification Helpers

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/exceptions.py`
- `packages/paaf-voice/src/paaf_voice/engines/base.py`
- `packages/paaf-voice/tests/test_model_cli.py`

**Implementation Details:**
1. Create `src/paaf_voice/exceptions.py`:
   - `VoiceError(Exception)`: base exception class for voice module.
   - `ModelMissingError(VoiceError)`:
     - Parameters: `engine_name: str`, `model_name: str`, `cache_dir: str`.
     - Message format: `"STT model '{model_name}' for engine '{engine_name}' not found in {cache_dir}. Run 'paaf voice download-models --engine {engine_name} --model {model_name}' to download with explicit consent."`
2. Implement model path verification helpers `verify_model_present(engine_name: str, model_name: str, cache_dir: Path) -> Path`:
   - Returns valid model directory or raises `ModelMissingError`.
3. Add tests in `tests/test_model_cli.py` verifying `ModelMissingError` formatting and weight checks.

**Verification Command:**
