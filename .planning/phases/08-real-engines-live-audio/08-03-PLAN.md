# Executive Summary & Intent

Plan 03 delivers real cross-platform live audio hardware input and output adapters using `sounddevice` (PortAudio wrapper) following decisions D-06, D-07, and D-08.

`SoundDeviceAudioSource` streams live 16kHz 16-bit mono microphone PCM frames (20ms / 320 samples per chunk). `SoundDeviceAudioSink` plays TTS audio out of physical speakers using `soxr` for dynamic sample rate conversion (converting Chatterbox 22.05kHz/24kHz TTS streams to output soundcard rates such as 44.1kHz or 48kHz). In addition, `SoundDeviceAudioSink` maintains a thread-safe ring buffer, tracks playhead position in seconds (`get_playhead_position()`), and exposes played PCM bytes via `get_reference_tap()` for downstream acoustic echo cancellation (AEC).

Finally, `paaf voice list-devices` lists all connected audio hardware input and output devices.

## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Audio Thread Safety & Resource Exhaustion
- **Threat**: PortAudio C audio callbacks blocking on Python locks or memory allocations, causing audio xruns (crackling), GIL deadlocks, or runaway memory buffer growth.
- **Impact**: Distorted audio playback, high CPU utilization, stream crash during live voice turns.
- **Mitigation Strategy**:
  1. PortAudio callback copies bytes cleanly to a thread-safe lock-free buffer (`collections.deque(maxlen=N)` or `queue.SimpleQueue`) without acquiring GIL-heavy locks.
  2. Dynamic resampling via `soxr` executes in Python thread workers rather than inside the low-level C audio callback.
  3. Bounded ring buffer length capping total stored reference tap bytes.
</threat_model>

**Implementation Details:**
1. Create `src/paaf_voice/audio/sounddevice_io.py`:
   - `SoundDeviceAudioSource(AudioSource)`:
     - Constructor: `device_index: int | str | None = None`, `sample_rate: int = 16000`, `channels: int = 1`.
     - `start()`, `stop()` lifecycle methods.
     - `read_frames(frame_duration_ms=20)`: opens `sounddevice.InputStream`, streams PCM 16kHz 20ms chunks (`AudioFrame`).
   - `SoundDeviceAudioSink(AudioSink)`:
     - Constructor: `device_index: int | str | None = None`, `target_sample_rate: int = 48000`.
     - `write_frame(frame)`: resamples input frame to `target_sample_rate` via `soxr.resample()`, pushes to PortAudio output stream (`sounddevice.OutputStream`), records played sample count into virtual playhead tracker, and appends to reference tap ring buffer.
     - `get_playhead_position() -> float`: calculates played time in seconds.
     - `get_reference_tap() -> bytes`: yields played PCM reference bytes for AEC.
2. Create `tests/test_audio_io.py`:
   - Unit test `SoundDeviceAudioSink` playhead tracking and `soxr` resampling.
   - Assert reference tap yields expected PCM bytes matching playhead duration.
   - Assert fallback handling when physical audio devices are missing (mocked streams).
