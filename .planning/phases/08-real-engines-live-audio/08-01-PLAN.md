# Executive Summary & Intent

Plan 01 delivers the strategic **Engine Registry** (`paaf_voice.engines`) and PAAF's out-of-the-box dual STT engine adapters. Following decisions D-01, D-02, and D-03, the registry uses dynamic decorator-based registration (`@register_stt_engine("name")`, `@register_tts_engine("name")`) allowing users to switch STT engines in YAML configuration (`engine: "whisper_cpp"` vs `engine: "faster_whisper"`) with zero code modifications.

Out-of-the-box adapters include:
1. `FasterWhisperSTT` (`faster-whisper` / CTranslate2) for Mac (MPS), CUDA, and high-performance desktop CPUs.
2. `WhisperCppSTT` (`pywhispercpp` / `whisper.cpp` GGML quantized models) for Raspberry Pi 4/5 and low-resource ARM SBCs (~150-300MB RAM footprint).

Both STT adapters implement `STTPort`, auto-detect languages (`language=None`), emit streaming partial transcription results, and support per-language engine overrides (VOICE-05).

## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Input Validation & Unchecked Dynamic Registration
- **Threat**: Malicious input in YAML `engine` parameter requesting arbitrary unregistered string keys or attempting code injection via module paths.
- **Impact**: Unhandled `KeyError` or arbitrary code execution during voice pipeline boot.
- **Mitigation Strategy**:
  1. Strict string validation in `EngineRegistry` matching `[a-z0-9_-]+`.
  2. Clear `ValueError` raised on unregistered engine names, returning available registered engine keys in exception message.
  3. No dynamic string evaluation (`eval`/`exec`) — registration uses an explicit in-memory dictionary mapping registry keys to decorated class types.
</threat_model>

### Task 2: Implement Dual STT Engine Adapters (faster-whisper & whisper.cpp)

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/engines/faster_whisper.py`
- `packages/paaf-voice/src/paaf_voice/engines/whisper_cpp.py`
- `packages/paaf-voice/src/paaf_voice/engines/__init__.py`
- `packages/paaf-voice/tests/test_stt_engines.py`

**Implementation Details:**
1. Create `src/paaf_voice/engines/faster_whisper.py`:
   - `@register_stt_engine("faster_whisper")`
   - Class `FasterWhisperSTT(STT)`:
     - Constructor: `model_size_or_path: str = "base"`, `device: str = "auto"`, `compute_type: str = "default"`, `download_root: str | None = None`.
     - `warmup()`: loads model weights, runs dummy inference pass on 20ms silence frame.
     - `transcribe_stream()`: accepts `AsyncIterable[AudioFrame]`, buffers PCM bytes into VAD segments, runs `WhisperModel.transcribe()` with `language=None` (auto-detection), yields `STTResult` with `is_final` flag.
2. Create `src/paaf_voice/engines/whisper_cpp.py`:
   - `@register_stt_engine("whisper_cpp")`
   - Class `WhisperCppSTT(STT)`:
     - Constructor: `model_path: str = "ggml-base.bin"`, `n_threads: int = 4`.
     - Optimized for low-RAM ARM64 / Raspberry Pi devices.
     - `warmup()`: pre-loads GGML weights, executes 20ms silence pass.
     - `transcribe_stream()`: processes PCM audio frames and yields `STTResult`.
3. Update `src/paaf_voice/engines/__init__.py` to re-export decorators, factory methods, and engine classes.
4. Create `tests/test_stt_engines.py`:
   - Unit test `FasterWhisperSTT` and `WhisperCppSTT` using WAV audio fixtures.
   - Assert streaming `STTResult` output format.

**Verification Command:**
