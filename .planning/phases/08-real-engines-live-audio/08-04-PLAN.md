# Executive Summary & Intent

Plan 04 implements the real wake word engine adapter (`OpenWakeWordEngine`) and continuous Voice Activity Detection engine adapter (`SileroVADEngine`) following decisions D-09 and D-10.

`OpenWakeWordEngine` implements `WakeWordPort` backed by `openwakeword` ONNX models, supporting built-in models (`hey_jarvis`, `alexa`) and custom ONNX model paths specified in YAML. `SileroVADEngine` implements `VADPort` backed by `onnxruntime` and Silero VAD v4/v5 ONNX models. It runs continuously even during audio playback, using dynamic dual thresholds (`speech_threshold=0.65` during active TTS playback vs `0.50` when idle) to prevent acoustic speaker bleed false triggers.

## Threat Model (ASVS Level 1 Compliance)

### ASVS Category: Resource Contention & Denial of Service
- **Threat**: Continuous background VAD processing spawning unbounded ONNX threads or overloading CPU on single-board computers (Raspberry Pi).
- **Impact**: CPU exhaustion, high latency, dropped audio frames.
- **Mitigation Strategy**:
  1. `onnxruntime` SessionOptions explicitly configured for single-thread intra-op execution on ARM (`intra_op_num_threads=1`).
  2. Input audio chunking strictly fixed at 20ms (320 samples @ 16kHz) for low-overhead tensor reshaping.
  3. Pre-allocated numpy input arrays reused across inference frames.
</threat_model>

### Task 2: Implement `SileroVADEngine` Continuous Dual-Threshold Adapter

**Files Modified:**
- `packages/paaf-voice/src/paaf_voice/engines/silero_vad.py`
- `packages/paaf-voice/src/paaf_voice/engines/__init__.py`
- `packages/paaf-voice/tests/test_wakeword_vad.py`

**Implementation Details:**
1. Create `src/paaf_voice/engines/silero_vad.py`:
   - `@register_vad_engine("silero")`
   - Class `SileroVADEngine(VAD)`:
     - Constructor: `model_path: str | None = None`, `speech_threshold_idle: float = 0.50`, `speech_threshold_playback: float = 0.65`.
     - `set_playback_active(active: bool) -> None`: toggles state between idle vs active playback.
     - `warmup()`: loads Silero ONNX model session, initializes hidden states `h`, `c`, and executes 20ms silence pass.
     - `process_frame(frame: AudioFrame) -> VADResult`: runs ONNX inference on 20ms frame, compares raw speech probability against current active threshold (`0.65` during playback vs `0.50` when idle), and updates internal recurrent state tensors.
2. Update `src/paaf_voice/engines/__init__.py` re-exports.
3. Add unit tests in `tests/test_wakeword_vad.py`:
   - Assert VAD detects speech on WAV audio frames.
   - Assert threshold switches from 0.50 to 0.65 during simulated playback mode.
