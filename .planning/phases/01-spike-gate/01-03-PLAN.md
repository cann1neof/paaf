<objective>
Provision the isolated **voice venv** and pass **GATE 0** — the engine-readiness gate that fails loudly
if any silent-degradation path is active — before a single clip is rendered for judgment. This is the
single highest-leverage task in the phase: `ChatterboxMultilingualTTS` routes Hebrew through
`add_hebrew_diacritics()`, which imports the UNDECLARED `dicta_onnx`; when absent it logs a warning and
passes consonant-only text through, which would make SPIKE-02 condemn the model for a missing pip install
(Pitfall 1). Judging Hebrew before this gate is green wastes the one irreplaceable resource in the phase —
a first, unprimed native-ear impression.

Purpose: guarantee SPIKE-02's Hebrew verdict and SPIKE-01's tagging measure a correctly assembled config.
Output: voice venv + Gate 0 readiness harness + recorded device/seed/version baseline.
</objective>
