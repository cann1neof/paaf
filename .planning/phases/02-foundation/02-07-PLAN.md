<objective>
Build the local SQLite trace store in `paaf-trace`: WAL mode, a single writer task owning the connection, producers feeding a bounded `asyncio.Queue` off the audio hot path (TRACE-01); a schema recording prompts, selected model, tool calls with args and results, timings, and token counts (TRACE-02); `time_to_first_audio` as a first-class column (TRACE-03); and a proof that nothing in the trace store leaves the device (TRACE-05). Raw SQL + aiosqlite, no ORM. This is the SC#5 trace-store half; Plan 09 adds the CI TTFA regression gate on top.

Phase Goal (developer-as-user story): **As a** user inspecting what my assistant did, **I want** every run's prompts, model, tool calls, timings and token counts stored locally and never sent anywhere, **so that** I can audit my assistant's behavior on my own machine with nothing hidden and nothing leaked.

Purpose: The trace schema is a durable contract the desktop Logs page and the TTFA gate both depend on; the off-hot-path discipline protects realtime audio latency in later phases.
Output: `schema.sql`, `store.py` (queue + single writer), `metrics.py`, and tests including the off-hot-path and no-egress negative controls.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hot path (audio) → trace queue | blocking on disk I/O would stall realtime audio in later phases |
| trace store → network | any egress of trace data breaks TRACE-05 / the privacy commitment |
| multiple writers → SQLite | writer contention causes `database is locked` / lost writes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-17 | Denial of Service | audio hot path | high | mitigate | emit() put_nowait + drop-counter, never awaits (Pitfall 5 / Anti-Pattern); off-hot-path negative control |
| T-02-18 | Information Disclosure | trace data egress | high | mitigate | no net client in graph (Plan 02 forbidden contract) + runtime `--disable-socket` no-egress test (TRACE-05) |
| T-02-19 | Tampering/DoS | SQLite writer contention | medium | mitigate | single writer + WAL + synchronous=NORMAL + busy_timeout (Pitfall 5) |
</threat_model>
