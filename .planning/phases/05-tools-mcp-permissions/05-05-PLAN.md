<objective>
Enforce prompt injection non-defensive governance via CI verification test per TOOL-07 and D-18.

This plan audits system prompt composition across all PAAF agents and mesh components, asserting that permission tiers are PAAF's sole defense against prompt injection via tool outputs, and verifying that zero hidden defensive prompt instructions exist anywhere in system prompts (PERS-05).
</objective>

<threat_model>
- **Threat:** Hidden defensive prompt instructions slipping into agent or mesh system prompts, violating PAAF's core principle ("nothing hidden from the user", PERS-05) and obscuring prompt inspectability.
  - **Mitigation:** Automated CI test `test_no_hidden_defense.py` scans composed prompts across all agents, profiles, and mesh configurations to assert 100% absence of hidden defensive phrases.
- **Threat:** Insecure handling of untrusted tool output causing prompt injection hijacking.
  - **Mitigation:** TOOL-07 explicitly mandates permission tiers (`observe`, `act`, `confirm`) as the ONLY injection defense mechanism. Injection via tool outputs is constrained by tool registry grants and permission tier interlocks.
</threat_model>
