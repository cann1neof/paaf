<objective>
Implement always-on built-in system tools (`date_time_lookup`, `history_lookup`, `handoff`, and Observer decision tools) and integrate peer graph awareness directly into system prompts without a `list_peers` tool.

This tracer bullet establishes the core built-in tool primitives, extends `paaf-trace` with a `custom_events` table for background event logging, and wires `history_lookup` to query past turn runs, tool calls, and background events off the hot execution path.
</objective>

<threat_model>
- **Threat:** Malicious prompt or tool result attempting to discover network topology via a `list_peers` tool.
  - **Mitigation:** Peer graph awareness is injected directly into system prompts during prompt composition (D-01). A `list_peers` tool is explicitly forbidden, preventing agents from dynamically scanning or querying ungranted peers.
- **Threat:** Uncontrolled SQLite queries blocking the main execution path or locking the database.
  - **Mitigation:** `history_lookup` queries `paaf-trace` using read-only connection handles in SQLite WAL mode with bounded result limits, keeping database operations isolated from the audio/turn execution path.
</threat_model>
