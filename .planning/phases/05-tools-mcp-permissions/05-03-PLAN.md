<objective>
Implement Model Context Protocol (MCP) server lifecycle management and configuration integration in `paaf-core` and `paaf-llm`.

This plan provides non-blocking MCP server startup for both `stdio` and `sse` transports, declarations in `paaf.yaml`, and interactive CLI helper commands (`paaf mcp add/list/remove`).
</objective>

<threat_model>
- **Threat:** Failing or hanging MCP external server process blocking assistant startup or causing event loop lockup.
  - **Mitigation:** `McpServerManager.initialize_all()` runs with a strict startup timeout (`timeout_s=5.0`) per server (D-12). Failed servers are logged as warnings and marked `OFFLINE`. Assistant startup proceeds normally. Invoking a tool on an offline server returns a clean error string to the agent without crashing.
- **Threat:** Arbitrary shell injection via CLI `paaf mcp add`.
  - **Mitigation:** MCP `stdio` server configs store explicit argument arrays (`command` string + `args` list) rather than passing raw strings to shell execution (`shell=False`).
</threat_model>
