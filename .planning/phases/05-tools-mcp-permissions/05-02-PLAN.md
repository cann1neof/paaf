<objective>
Implement the custom `@tool` Python function decorator and reflection engine in `paaf-llm`.

The `@tool` decorator enables users to decorate standard sync or async Python functions into PAAF `ToolSpec` declarations with automatic JSON Schema extraction via `inspect.signature` and docstring parsing, supporting safe execution dispatch across asyncio event loops and worker thread pools.
</objective>

<threat_model>
- **Threat:** Synchronous blocking tool functions stalling the main `asyncio` event loop and freezing voice/turn processing.
  - **Mitigation:** Execution dispatcher detects non-async functions via `inspect.iscoroutinefunction` and offloads synchronous calls to `asyncio.to_thread` (ThreadPoolExecutor).
- **Threat:** Invalid parameter schemas leading to adapter crashes or unhandled model failures.
  - **Mitigation:** Strict reflection validation maps Python type hints (`int`, `float`, `str`, `bool`, `list`, `dict`) and default parameter values into compliant JSON Schema properties, defaulting unannotated arguments safely to `string`.
</threat_model>
