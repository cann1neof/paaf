## Phase Goal

**As a** developer who wants the agent framework to stay swappable, **I want to** talk to a single-method port whose entire surface is PAAF types, backed by a shipped fake I can drive deterministically, **so that** the whole library's correctness is proven with the real framework uninstalled — the proof the port is a port and not a mirror (SC#1).

<objective>
Build the framework-free heart of the port: the `ChatAdapter` Protocol (one async streaming method), the PAAF value types (`Message`, `Usage`, `TurnResult` with the Phase-4 `handoff` seam), the PAAF exception hierarchy that classifies every degraded trigger, and the shipped `FakeAdapter` that the entire test suite runs against with LangChain uninstalled. Wire the public `paaf_llm` surface to re-export ONLY PAAF types + `FakeAdapter` (never `_engine`, imported lazily). Because paaf-llm now legitimately depends on paaf-core (via ModelProfile), this plan also AMENDS the Phase-2 wheel-independence job — whose old negative control asserted `paaf_core` absent — so it now installs paaf-core/paaf-trace and asserts `paaf_voice` + `langchain` absent. This is the fake-first walking skeleton's foundation (SC#1): every later plan swaps behind this exact port.

Purpose: MODEL-08 (public API exposes only PAAF types; suite passes vs the fake with the framework uninstalled) — the port + fake + no-leak proof.
Output: `ports.py`, `fake/__init__.py`, re-exporting `__init__.py`, `conftest.py`, `test_no_leak.py`, and the amended wheel-independence job.
</objective>
