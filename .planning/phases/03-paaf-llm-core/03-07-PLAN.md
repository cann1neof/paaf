## Phase Goal

**As a** user who owns the assistant's mind, **I want to** run one command and see the exact prompt my model receives — nothing the framework added — and watch a conversation fall back cleanly when a provider drops, **so that** I can verify what my assistant is actually being told, without reading code.

<objective>
Build the thin human-facing surface: `paaf chat` (an interactive turn loop over `Agent.turn`, with `--show-prompt` and a brief inline fallback notice, surfacing each profile's manifest + peer graph as inert data) and `paaf prompt` (a dry-run that composes and prints the byte-exact prompt with no model call, plus the opt-in `--provenance` labeled view). Both prompt entry points call the SAME composer the agent uses (D-02) — one code path, no byte-drift — making `paaf prompt`/`--show-prompt` the mechanical enforcement of PERS-04/05. The CLI is deliberately thin (D-01): correctness lives in the library and is already proven against the fake; the CLI is tested by injecting the fake so it runs framework-uninstalled.

Purpose: SC#5 (one command prints the composed prompt verbatim, containing nothing the user did not write), PERS-04 (inspectable verbatim, exactly as sent), PERS-05 (nothing hidden), PERS-01/02 (base + fragments surfaced), MODEL-05 (manifest + peer graph surfaced, no handoff).
Output: `cli.py` and `test_inspector.py`.
</objective>
