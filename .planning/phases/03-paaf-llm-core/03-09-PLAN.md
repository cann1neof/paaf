## Phase Goal

**As a** developer trusting that the port is a real port, **I want to** prove the entire paaf-llm suite passes with the agent framework uninstalled — even after the real LangChain adapter has been added — **so that** MODEL-08's swappability guarantee is a standing CI gate, not a one-time claim (SC#1).

<objective>
Close SC#1 as a durable CI gate. Ship the fake-adapter test suite inside the wheel (force-include conftest + the fake tests) and add a dedicated CI job that installs the built paaf-llm wheel WITHOUT the `[engine]` extra — alongside its legitimate paaf-core/paaf-trace framework deps — and runs the full suite via `pytest --pyargs paaf_llm`, asserting `import langchain` raises `ModuleNotFoundError` while every fake-backed test is green. Placed LAST (after the real adapter in plan 03-08) so it proves the crucial property: adding the real `_engine` adapter did NOT make langchain a load-bearing import of the package (the adapter is lazy). This is the moment the phase's headline claim — "the port is a port, not a mirror" — becomes a build failure if it ever regresses.

Purpose: MODEL-08 / SC#1 (full suite passes vs the fake with the framework uninstalled) — as an enforced, repeatable CI gate.
Output: force-include wiring in `pyproject.toml`, a `check_framework_uninstalled.sh` script, and a `framework-uninstalled.yml` workflow.
</objective>
