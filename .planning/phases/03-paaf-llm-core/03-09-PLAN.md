Ship the fake-adapter test suite inside the wheel (force-include conftest + the fake tests) and add a dedicated CI job that installs the built paaf-llm wheel WITHOUT the `[engine]` extra — alongside its legitimate paaf-core/paaf-trace framework deps — and runs the full suite via `pytest --pyargs paaf_llm`, asserting `import langchain` raises `ModuleNotFoundError` while every fake-backed test is green.
