## Phase Goal

**As a** user who must be able to read the assistant's mind, **I want to** know that the prompt sent to my model is exactly the base prompt I wrote plus the skill fragments I enabled — and nothing the framework slipped in — **so that** "nothing hidden from the user" is a mechanical property, not a promise.

<objective>
Build the pure, deterministic prompt composer that is the single source of truth for the system prompt. It composes the base system prompt (PERS-01) with ordered skill persona fragments (PERS-02, from a stub source this phase per D-09) into the byte-exact string sent to the model, and exposes labeled provenance segments for the opt-in `--provenance` view. This composer is dependency-free (stdlib only) and lands in Wave 1; the agent (03-06) and the inspector CLI (03-07) both call it verbatim, so there is exactly one prompt-building code path and no byte-drift (RESEARCH anti-pattern: re-deriving the prompt for the inspector).

Purpose: PERS-01 + PERS-02 (base + skill fragments) and PERS-05 (nothing but what the user wrote) — the load-bearing "nothing hidden" invariant, built to show 100% of what is sent (D-10).
Output: `compose.py` and `test_compose.py`.
</objective>
